# NeoFit

NeoFit is an AI-powered physique analysis and fitness tracking platform developed as a final year BTech CSE project.

The system uses Computer Vision, MediaPipe landmark detection, pseudo-3D body reconstruction, and physiological analytics to estimate body measurements, track physique progress, and generate fitness insights.

---

## Features

- Real-time body landmark detection
- AI-assisted physique measurement system
- Pseudo-3D body reconstruction
- Chest, waist, hip, arm, and thigh estimation
- Historical physique tracking dashboard
- AI-based progress prediction
- Personalized diet planning system
- Session history and analytics
- Interactive frontend dashboard
